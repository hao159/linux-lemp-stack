v1.3.0

- Added: installer profiles Minimal (low-end VPS: plain Nginx, PHP-FPM, MariaDB, SSL, small Opcache) and Advanced (full set), followed by a checklist to switch every optional component on or off
- Added: Nginx third party modules are optional (Brotli, Headers-More, Lua, VTS, Cache Purge); only the chosen ones are downloaded and built, the list is kept for updates and rebuilds (/var/hostvn/nginx_modules)
- Added: menu LEMP -> Nginx -> Module Nginx to add or remove modules (rebuild with rollback, a module in use can not be removed)
- Added: phpMyAdmin, Opcache Dashboard, Composer, Rclone, Fail2ban are optional; installed later from Admin Tool / Firewall, or on first use (Laravel, Google Drive / OneDrive)
- Changed: CrowdSec / AppSec are in the component checklist, off by default; AppSec switches on CrowdSec and the Lua module
- Changed: WP-CLI packages are installed the first time they are used instead of during the installation
- Changed: response headers moved to /etc/nginx/extra/headers.conf (headers-more, or add_header without the module); Brotli config written for the modules really built
- Fixed: security headers set with headers-more had a wrong syntax (the value contained the quotes and "always")

v1.2.0

- Added: menu 14 "Cap nhat & canh bao": check and update Nginx, PHP, MariaDB, CrowdSec, OS packages, Scripts
- Added: Nginx update finds the newest release of its branch on nginx.org, the old binary is restored when it fails
- Added: daily check for updates, shown in the hostvn menu and sent to Telegram
- Changed: the installer is a step-by-step wizard (mode, email, IP, SSH port, PHP, web server, swap, CrowdSec, Telegram) with a summary to confirm before anything is installed; the --dev / --force options and WEBSERVER= are replaced by wizard questions
- Added: Apache (event MPM + PHP-FPM) can be chosen instead of Nginx in the installer
- Added: Apache behind Nginx for the websites that need .htaccess (menu LEMP -> Apache phia sau Nginx)
- Added: Apache mode: change domain, clone, redirect domain, SSL for alias domains, protected folders, WordPress protections (.htaccess), move VPS, CrowdSec reading the Apache logs
- Added: menu PHP -> install extensions (mongodb, redis, pgsql, intl, imagick, gd, zip ...) from Ondrej/Sury/Remi packages
- Added: optional Telegram Message Thread ID, notifications can go to one topic of a forum group
- Fixed: removing an alias domain deleted the vhost of the main website
- Fixed: Let's Encrypt "HTTP" validation used the CloudFlare DNS API; the web server is now reloaded when a certificate is renewed
- Fixed: deleting a website left its alias and redirect domains behind
- Fixed: WooCommerce cache file written with a wrong name, paid certificate path in the WordPress auto install
- Fixed: changing a domain with SSL left Nginx with a missing certificate path, the website file kept the old name
